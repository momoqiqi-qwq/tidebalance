# Le时间管理 v0.11.1

这是一次以效率、稳定性和后台资源占用为重点的维护更新。

## 性能与效率优化

- 新增状态批处理机制：自动排程、课程同步、考试提醒等循环操作不再为每一条记录触发一次全局刷新和保存，而是在批次结束后统一刷新、统一持久化。
- 数据保存改为串行队列，避免短时间内多个异步保存并发造成重复写盘和潜在的先后顺序覆盖问题。
- 新增 `persistSoon()`：导航位置、音量滑块、插件 storage 等高频轻量设置采用 350ms 防抖保存，不再每次输入都立即写盘。
- 自动化监听增加运行中抑制，自动化自己修改数据时不会再次触发一轮自动化扫描。
- 自动化定时执行按触发类型分流：状态变化只执行截止任务排程；考试提醒按小时；课程同步和每日整理只在跨日后执行一次，避免一天重复扫描。
- 截止任务自动排程预先建立“已排程任务 ID”集合，减少任务数和时间块较多时的重复全表扫描。
- 任务提醒从固定每 15 秒轮询改为自适应定时：有临近提醒时精准唤醒，没有临近提醒时最多每 5 分钟巡检一次；任务发生变化时会在 250ms 后重新计算下一次唤醒时间。
- 提醒触发记录现在会主动防抖持久化，减少记录丢失的概率。

## 兼容性

- 不改变现有任务、时间块、插件和自动化数据结构。
- Windows / Android 共用前端自动获得本次优化。
- 微信小程序数据结构保持兼容。

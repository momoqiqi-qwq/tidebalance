# Le时间管理 v0.6.0

## 设置入口
- Windows / Android WebView：将“设置”从普通侧栏导航中移出，固定到左下角；窄屏底栏同样将设置放在最左侧。
- 微信小程序：设置调整为底部 TabBar 最左侧入口。

## 任务截止提醒
- 任务详情新增“截止时间”，与截止日期组成精确截止时刻。
- 每个任务可独立启用/关闭提醒。
- 支持多级截止前预警：提前 1 天、2 小时、1 小时、30 分钟、10 分钟、5 分钟、到点，以及 0～43200 分钟自定义提前量。
- 已完成任务自动停止提醒，避免无效打扰。
- 桌面端运行期间每 15 秒检查提醒，切回前台时立即复查。
- 小程序前台活跃期间提供对应本地提醒；受微信后台机制限制，退出/冻结后不保证定时器持续运行。

## 声音
- 设置页新增任务提醒总开关、0～100% 音量调节、内置提示音/自定义提示音选择和试听。
- Windows / Android WebView 支持导入 MP3/WAV/M4A/AAC/OGG 等浏览器可播放音频，限制 8MB，并保存在应用数据备份中。
- 微信小程序支持从本机会话文件选择音频并保存为本地持久文件，再作为提醒音播放。

## 数据兼容
- 新字段：`dueTime`、`reminderEnabled`、`reminderOffsets`。
- 老任务无新字段时保持兼容：默认截止时刻为 23:59，预警使用全局默认值。

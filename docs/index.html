宿主 / Host lifecycle

插件如何进入潮衡

宿主发现插件目录，读取清单与入口文件，把受控的 tide 对象传给入口代码；插件随后注册视图、任务动作或事件监听。

DISCOVER扫描内置 ID 与桌面端用户插件目录
MANIFEST读取 manifest.json，确认入口文件
INJECT创建当前插件专属的 tide API
EXECUTE严格模式执行 main.js
REGISTER挂载视图、动作与事件监听
信任边界

入口由 new Function 执行，不是安全隔离；代码仍可能访问页面全局对象。当前 permissions 是声明与展示信息，宿主尚未按权限裁剪 API。只安装已审查、可信来源的插件。

最短路径 / Two-file start

十分钟做出第一页

文件夹名建议与插件 ID 一致。插件不需要 npm，也不需要打包；把两个文件放进数据目录下的 plugins/hello-tide/。

plugins/
└─ hello-tide/
   ├─ manifest.json
   └─ main.js

manifest.json

{
  "id": "hello-tide",
  "name": "潮汐问候",
  "version": "0.1.0",
  "author": "your-name",
  "icon": "潮",
  "description": "显示今天日期，并记录视图打开次数。",
  "permissions": ["ui", "storage", "notify"],
  "entry": "main.js"
}

main.js

tide.ui.registerView({
  id: "hello-tide",
  title: "潮汐问候",
  icon: "潮",
  async render(el) {
    const visits = await tide.storage.get("visits", 0);
    await tide.storage.set("visits", visits + 1);

    el.replaceChildren();
    const card = document.createElement("section");
    card.textContent = `今天是 ${tide.util.today()}，这是第 ${visits + 1} 次打开。`;
    el.append(card);
  }
});

tide.notify("插件已加载");
安装与刷新

桌面端：在“设置 → 数据”查看数据目录，把插件放进其中的 plugins/，然后在设置页点“重新扫描”。开发内置插件时，把目录放入 public/plugins/，并同步加入 pluginHost.js 的 BUILTIN_IDS。

契约 / Manifest contract

清单字段

字段用途与约束
id稳定、唯一的插件标识；推荐小写字母、数字与连字符。外部插件目录名应与它一致。
name面向用户的名称，通知会显示为“插件名：消息”。
version推荐语义化版本，例如 1.2.0。
author作者或组织名称。
icon侧栏短标识；建议使用单个汉字或稳定的单字符图标。
description说明用途、远端数据源、登录要求与敏感配置。
permissions声明使用的能力；当前用于说明与展示，不是运行时权限闸门。
entry入口脚本相对路径；省略时默认 main.js。

接口 / tide API

宿主注入的能力

tide 是插件约定入口。列表读取返回深拷贝；修改数据必须调用 create、update 或 remove，才能触发持久化。

身份、存储与界面

API说明
tide.id当前插件 ID。
tide.manifest解析后的当前插件清单。
storage.get(key, fallback)读取插件私有存储；键不存在时返回 fallback。
storage.set(key, value)写入插件私有存储并触发保存，返回 Promise；当前包装未等待底层写盘，await 不等于磁盘已写完。
ui.registerView(def)注册侧栏视图；def 包含 id、title、icon、render(el)。
ui.registerTaskAction(def)注册任务详情动作；def 包含 id、label、icon、run(task)。
notify(message, opts)显示带插件名前缀的 toast；可用 { ms: 5000 } 控制时长。

任务、时间块与事件

API说明
tasks.list()读取全部任务的安全拷贝。
tasks.create(patch)创建任务并返回完整对象。
tasks.update(id, patch)合并更新任务。
tasks.remove(id)删除任务，同时删除关联时间块。
blocks.list(date)读取指定 YYYY-MM-DD 日期的时间块。
blocks.create / update / remove创建、合并更新或删除时间块。
events.on(name, fn)订阅当前进程内事件。
events.emit(name, data)广播当前进程内事件；建议命名为 plugin-id:event。

网络与工具

API说明
http.get(url)通过 Rust 网络桥发 GET；返回 { status, body, finalUrl, contentType }。
http.session()创建 Cookie Jar 会话，返回会话 ID。
http.fetch(sid, method, url, opts)会话请求；opts 支持 headers、body、binary。二进制响应 body 为 Base64。
util.openUrl(url)用系统浏览器打开 http/https 链接。
util.parseWhen(text)解析中文日期时间，返回 date、startMin、endMin、title 等字段。
util.guessCategory(text)按关键词推测 work、study、sport、life、rest。
util.guessQuad(date)按截止日期推测四象限。
util.navigate(view)导航到宿主视图。
util.desEncryptHex(plain, key)Tauri/Rust 端 DES-ECB/PKCS5 加密；浏览器调试模式不可用。
util.today / addDays日期工具。
util.mmOf / hhmmOf / durLabel分钟、HH:mm 与时长标签互转。

数据 / Data shapes

任务与时间块

TASK

决策对象

quad 为 1–4；due 使用 YYYY-MM-DD；estMin 是预计分钟；done 表示完成。

BLOCK

日程对象

date 是日期，start 为 HH:mm，durMin 为分钟；taskId 可关联任务。

const task = tide.tasks.create({
  title: "整理插件适配清单",
  note: "先桌面端，再 Android 内置",
  quad: 2,
  estMin: 45,
  tags: ["插件", "开发"],
  project: "TideBalance",
  due: tide.util.today()
});

tide.blocks.create({
  date: tide.util.today(),
  start: "14:00",
  durMin: 45,
  title: task.title,
  taskId: task.id,
  cat: "work"
});

方案 / Adaptation patterns

四种常用适配

REMOTE → REMINDER

把外部消息转成提醒

用 HTTP 桥拉取，先把远端内容规范化，再交给 parseWhen；创建任务后再创建关联时间块。不要把未清洗 HTML 直接写入 innerHTML。

STATE → VIEW

保存偏好与进度

筛选器、已读 ID 和刷新时间放入私有 storage。避免长期明文保存密码、令牌或 Cookie；对必要凭据说明风险。

TASK → ACTION

扩展任务动作

动作 ID 保持稳定，传入 task 只用于读取上下文；修改统一走 tasks.update，不要直接改对象。

EVENT → LOOSE COUPLING

插件间松耦合

使用 plugin-id:event-name 命名。事件总线仅当前进程有效，不是可靠队列，也不保存历史消息。

带登录态的请求

const sid = await tide.http.session();
const login = await tide.http.fetch(sid, "POST", "https://example.com/login", {
  headers: { "Content-Type": "application/x-www-form-urlencoded" },

if (login.status !== 200) {

矩阵 / Platform boundaries

先决定插件运行在哪

WINDOWS / LINUX DESKTOP

完整路径

支持外部插件扫描、文件读取、Rust 网络桥、Cookie 会话、系统浏览器与 DES 工具。

ANDROID

随应用内置

当前不扫描外部目录。将插件放进 public/plugins/，加入 BUILTIN_IDS，随安装包一起构建。

BROWSER DEV

有限降级

数据落 localStorage；不发现外部插件；HTTP 受浏览器 CORS/Cookie 策略限制；DES 不可用。

WECHAT MINIPROGRAM

不可直接复用

小程序版共享数据格式和时间解析思路，但没有插件宿主；需改写为小程序页面或连接桌面端局域网服务。

计时器与清理

插件停用时，宿主会移除注册的视图、任务动作和事件订阅，但不会自动清理插件自行创建的 setInterval、DOM 全局监听或全局样式。需要重复扫描/启停的插件应避免重复注册全局副作用，或自行设计幂等清理。

交付 / Test & release

发布前逐项过一遍

  1. 清单可解析
    JSON 无注释、ID 与目录匹配、entry 存在、版本已更新。
  2. 声明真实能力
    只列实际使用的 permissions；description 写清远端服务、登录与必要配置。
  3. 验证完整生命周期
    首次加载、停用、重新启用、重新扫描、应用重启都不产生重复视图或计时器。
  4. 检查数据写入
    创建、更新、删除任务/时间块后重启应用，确认持久化与关联删除符合预期。
  5. 覆盖失败分支
    断网、非 2xx、返回结构改变、登录过期、空列表与存储损坏时给出可行动提示。
  6. 检查页面安全
    远端文本用 textContent 或转义后渲染；外链限制为可信 http/https；不记录凭据。
  7. 做目标平台实测
    桌面外置插件在真实数据目录验证；Android 内置插件必须随 APK 构建测试。

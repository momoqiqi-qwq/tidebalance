# Le时间管理 v0.5.0

## 插件使用说明
- 新增「插件使用说明」内置插件。
- 按「学习与校园 / 效率与专注 / 信息与提醒 / 生活与工具」分组。
- 每个插件独立卡片展示用途、操作步骤、平台支持和注意事项，响应式排列。

## 番茄专注
- 新增 1–240 分钟自定义倒计时，并记住上次设置。
- 可在番茄页面直接输入任务名称并创建任务，创建后自动选中关联。
- 自定义专注完成后按实际自定义分钟数累计统计，不再固定按 25 分钟计算。
- Windows / Android 共用插件实现；微信小程序原生番茄页同步支持自定义倒计时和新建任务。
- 修复桌面端任务列表刷新时重复绑定 change 监听的问题。

- 微信小程序核心测试 46/46 通过，静态检查通过。

# Le时间管理 v0.10.0 路线图 / 落地状态

## v0.10.0 已落地（P0）

1. **可选同步层**：新增 WebDAV JSON 快照的手动上传/下载。本地优先不变，不要求账号；只保存 URL/用户名，密码不落盘。
2. **插件权限管理**：manifest 声明的任务、时间块、存储、通知、事件、网络、外链、时间解析等能力增加运行时 API 权限开关。当前属于宿主 API 能力隔离，不宣称是独立进程级安全沙箱。
3. **全局搜索 / 命令面板**：Ctrl/Cmd+K 统一搜索任务、时间块、插件和常用命令；桌面安装版支持系统级全局快捷键。
4. **冲突检测 2.0**：新增冲突预览、附近空闲时段建议、拖拽/编辑冲突提示，以及插件 `blocks.preview/createSmart`。
5. **插件搜索管理**：插件中心、设置页和微信小程序插件页都增加搜索/筛选。

## 警大通知后续建议

当前实现是“保存学号 + 当前运行会话的 SSO/Cookie 静默续期”，**没有保存密码，也没有 OCR 自动识别验证码**。如下一版要做到重启后更接近自动登录，建议采用：

1. 密码仅写入 Windows Credential Manager / Android Keystore 等系统凭据库，不放进 data.json 或插件 storage；
2. 验证码 OCR 完全本地化并保留人工确认，识别失败时回退手输；
3. 登录失败、验证码错误、票据过期要有限重试，避免账户锁定；
4. 设置里提供显式“允许自动登录”开关和“清除凭据”。

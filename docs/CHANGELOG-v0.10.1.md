# v0.10.1

- 考试日历增加“只看某一个考试”筛选，可按 CET4、CET6、NCRE、NTCE、考研、TEM4、TEM8 查看该考试已收录的完整流程。
- 每条考试新增“看全流程”入口，进入后会显示报名、预报名、准考证打印、口试/笔试等同一考试相关阶段。
- 增加报名时间说明：优先显示离线官方数据中已收录的报名起止时间；没有统一时间时明确提示以官网与学校/考点通知为准。
- CET4/CET6 增加专门提示：各省、学校或考点报名时间可能不同，请按所在学校规定时间登录 CET 全国网上报名系统（cet-bm.neea.edu.cn）完成资格审核、笔试报名缴费及口试报名缴费。
- Windows/Android 与微信小程序原生考试日历同步支持上述筛选与报名提示。

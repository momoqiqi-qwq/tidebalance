00

为什么选 Workers Static Assets

这份手册是没有服务端状态的单文件站点，直接作为 Worker 的静态资产发布。

Workers Static Assets · 采用静态文件按 Worker 资产部署、全球分发、自动 HTTPS；后续需要 API、鉴权或动态路由时可原地扩展。
Pages · 仅作兼容Pages 仍可使用，但 Cloudflare 当前把 Workers 作为新项目的主要平台。
D1 / KV / R2 · 暂不需要文档没有数据库、配置状态或独立大文件存储需求。
部署模式：Assets-only Worker

wrangler.jsonc 通过 assets.directory 指向 ./public，不需要 main 入口或任何运行时绑定。Wrangler 会把静态资产与 Worker 配置作为一个部署单元发布。

01

先理解插件如何进入Le时间管理

插件宿主按固定顺序发现、读取、注入并注册扩展。

1扫描目录桌面端枚举数据目录下的 plugins/*
2读取清单解析 manifest.json，入口默认 main.js
3注入 API宿主构造当前插件专属的 tide 对象
4执行入口严格模式执行代码，完成视图与动作注册
5生命周期停用时移除视图、动作和事件订阅
插件必须被视为可信代码

当前入口通过 new Function 执行，并不构成安全隔离；插件可以使用 DOM 全局对象。permissions 当前用于声明和设置页展示，宿主尚未按权限裁剪 API。只安装来源可信、经过审查的插件。

02

两文件快速开始

无需 npm、打包器或框架。文件夹名最好与插件 ID 一致。

plugins/
└─ hello-tide/
   ├─ manifest.json
   └─ main.js

manifest.json

{
  "id": "hello-tide",
  "name": "今日一句",
  "version": "0.1.0",
  "author": "your-name",
  "icon": "句",
  "description": "在侧边栏显示一句今日提示。",
  "permissions": ["ui", "storage", "notify"],
  "entry": "main.js"
}

main.js

(function () {
  tide.ui.registerView({
    id: "hello",
    title: "今日一句",
    icon: "句",
    async render(container) {
      const count = await tide.storage.get("visits", 0);
      await tide.storage.set("visits", count + 1);

      const card = document.createElement("section");
      card.style.cssText = "max-width:560px;margin:36px auto;padding:28px;background:#fff;border:1px solid #ddd";
      card.textContent = `今天是 ${tide.util.today()}，这是第 ${count + 1} 次打开。`;
      container.replaceChildren(card);
    },
  });

  tide.ui.registerTaskAction({
    id: "encourage",
    label: "给我一点鼓励",
    icon: "✓",
    run(task) { tide.notify(`继续推进「${task.title}」`); },
  });
})();

把文件夹复制到「设置 → 数据」显示的数据目录下的 plugins/，然后在「设置 → 插件」点击「重新扫描」。加载失败原因会直接显示在插件卡片中。

03

Manifest 字段

清单用于发现、标识和向用户解释插件能力。

字段用途与约束
id稳定且唯一，建议小写字母、数字和短横线；应与目录名一致，避免状态命名空间混乱。
name设置页和提示消息中显示的名称。
version建议使用 SemVer，例如 1.2.0。
author作者或维护组织。
icon短文本或单个字符；侧栏会直接显示。
description说明数据来源、主要行为和必要配置，避免只写宣传语。
permissions声明使用的能力。当前版本是可见性声明，不是运行时权限闸门。
entry入口路径，省略时为 main.js；路径必须位于插件目录内。

可声明权限

uitasksblocksstoragenotifyeventshttpopenUrltimeParse
04

tide API 参考

插件唯一约定入口。数据集合读取时返回安全拷贝。

身份与清单

tide.id当前插件 ID。
tide.manifest当前插件解析后的清单对象。

任务与时间块

tasks.list()返回所有任务的深拷贝数组。
tasks.create(patch)创建任务。常用字段：title、quad、due、estMin、tags、project。
tasks.update(id, patch)更新指定任务。
tasks.remove(id)删除指定任务。
blocks.list(date)返回某日时间块，例如 2026-09-08。
blocks.create(patch)创建时间块。常用字段：date、start、durMin、title、taskId、cat。
blocks.update(id, patch)更新时间块。
blocks.remove(id)删除时间块。

存储、界面与事件

storage.get(key, fallback)异步读取插件私有命名空间，空值返回 fallback。
storage.set(key, value)异步保存 JSON 可序列化值，并触发主数据写盘。
ui.registerView(def)注册侧栏视图：{ id, title, icon, render(container) }。
ui.registerTaskAction(def)注册任务动作：{ id, label, icon, run(task) }。
notify(message, options?)显示带插件名称前缀的应用内提示。
events.on(name, handler)订阅进程内事件；停用插件时自动移除订阅。
events.emit(name, data)同步广播插件事件。建议事件名加插件前缀。

网络与工具

http.get(url)GET 请求，仅允许 HTTP/HTTPS；桌面端经 Rust 发出并绕开 WebView CORS。
http.session()创建带 Cookie Jar 的会话，返回会话 ID。
http.fetch(sid, method, url, opts)会话请求；支持 GET/POST/PUT/DELETE、headers、body、binary。二进制响应 body 为 Base64。
util.openUrl(url)用系统默认浏览器打开 HTTP/HTTPS 链接。
util.parseWhen(text)解析中文日期时间，返回 date/startMin/endMin/title 等字段。
util.guessCategory(text)推测 work/study/sport/life/rest 分类。
util.guessQuad(date)根据期限推测四象限。
util.navigate(view)跳转主视图，插件视图可用 plug:视图ID。
util.desEncryptHex(plain, key)桌面端 DES-ECB/PKCS5 加密并返回 Hex；key 必须为 8 字节。
util.today() / addDays()日期工具。
util.mmOf() / hhmmOf() / durLabel()时间与时长格式工具。
05

常用适配模式

从Le时间管理已有插件提炼的可复用写法。

DATA → REMINDER

把外部消息转成提醒

先用 http 拉取，交给 parseWhen 识别时间，再同时创建任务和时间块。远端 HTML 必须先净化，禁止直接注入 innerHTML。

STATE → VIEW

保持插件偏好

筛选器、已读 ID、计数等写入 storage。不要把账号密码长期明文保存；敏感配置应尽量由用户每次输入。

TASK → ACTION

扩展任务动作

动作 ID 在插件内保持稳定；传入的 task 用于读取上下文，修改统一走 tasks.update，让宿主完成持久化。

EVENT → LOOSE COUPLING

插件间松耦合

使用 plugin-id:event-name 命名。事件总线只在当前运行进程有效，不承担历史消息或可靠队列职责。

网络会话示例

const sid = await tide.http.session();

const login = await tide.http.fetch(sid, "POST", "https://example.com/login", {
  headers: { "Content-Type": "application/x-www-form-urlencoded" },
  body: new URLSearchParams({ username, password }).toString(),
});
if (login.status < 200 || login.status >= 400) {
  tide.notify(`登录失败：HTTP ${login.status}`);
  return;
}

const feed = await tide.http.fetch(sid, "GET", "https://example.com/api/feed");
const rows = JSON.parse(feed.body);
06

平台与安全边界

写插件前先确定它在哪些运行环境中成立。

WINDOWS / LINUX DESKTOP

完整支持

外部目录扫描、文件读取、Rust 网络桥、Cookie 会话、系统浏览器与 DES 工具均由 Tauri 后端提供。

ANDROID

仅内置插件

当前项目说明明确：Android 暂不支持外部目录扫描。需要随应用发布的插件应放入 public/plugins/ 并加入宿主内置 ID 列表。

BROWSER DEV

部分降级

用户插件列表为空；数据落 localStorage；网络改用浏览器 fetch，受 CORS 与 Cookie 策略限制；DES 不可用。

MINIPROGRAM

不支持插件宿主

微信小程序版共享数据格式与时间解析思路，但没有桌面端插件系统，不能直接复用 main.js。

网络边界仍需主动校验

Rust 桥只检查 URL 以 http:// 或 https:// 开头。插件应自行限制可信域名、校验 HTTP 状态和响应结构、设置合理刷新频率，并避免在日志或提示中泄露凭据。

07

测试与发布清单

用最短路径排除最常见的插件故障。

  • 结构：目录包含可解析的 manifest.json，entry 文件存在，ID 与目录名一致。
  • 声明：只列出实际使用的 permissions，并在 description 里写清远端数据源与必要配置。
  • 视图：重复进入视图不会重复挂事件或定时器；render 使用传入 container，空状态和失败状态可操作。
  • 数据：所有 storage 值可被 JSON 序列化；任务、时间块字段完整；删除操作提供明确确认。
  • 网络：测试超时、非 2xx、HTML 错误页、JSON 字段缺失、登录过期与跨域降级。
  • 生命周期：停用/启用、重新扫描后无重复视图、重复事件订阅或悬挂计时器。
  • 兼容：如果使用 desEncryptHex、外部目录或 Cookie 会话，明确标注仅 Tauri 桌面端。
  • 安装：复制到数据目录 plugins/，重新扫描，检查设置页错误，再覆盖一条真实业务路径。
